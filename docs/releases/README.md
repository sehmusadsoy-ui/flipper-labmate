This directory holds the **source repository's Markdown release notes**
for previously published milestones. Historical GitHub tags and release
assets remain available unchanged.

**v1.1** is a historical development milestone, not a separately
published GitHub release/tag. Existing older releases were built for
particular Momentum SDK/API versions; a historical Stable FAP is **not**
guaranteed to work on official Flipper firmware or arbitrary third-party
firmware. The E11 pre-release **specifically requires patched, matched
Momentum firmware/native resources** and is not a general replacement
for original [v1.8 Stable](https://github.com/sehmusadsoy-ui/flipper-labmate/releases/tag/v1.8).

**Download releases from [GitHub Releases](https://github.com/sehmusadsoy-ui/flipper-labmate/releases)**,
not from this documentation directory.

Older notes may describe the **file paths and procedures of their own
historical version**. For the current v1.8 `src/` layout and version-specific
downloads, use the [repository README](../../README.md).
The [v1.7 installation guide](../V1_7_INSTALL_GUIDE.md) documents
historical v1.7 only, not E11 custom firmware installation.
The official v1.7 release tag remains unchanged, though its binary was
transparently updated in place for the PWM Studio menu naming correction.
